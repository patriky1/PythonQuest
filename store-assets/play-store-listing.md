## Detalhes do app

**Nome do app** (máx. 30)
```
PythonQuest: Aprenda Python
```

**Descrição curta** (máx. 80)
```
Aprenda Python jogando: missões curtas, XP, medalhas e um terminal de verdade.
```

**Descrição completa** (máx. 4000)
```
Aprenda Python do zero como quem joga um jogo.

O PythonQuest transforma a programação em uma jornada: lições curtas, desafios práticos e recompensas a cada passo. Do print() aos dicionários, você avança uma fase de cada vez, no seu ritmo, direto do celular.

🗺️ TRILHA DE MISSÕES
Uma trilha organizada por módulos, do básico ao intermediário. Cada missão mistura explicação, quiz e código para você entender o conceito e colocar em prática na hora.

🐍 PYTHON DE VERDADE NO CELULAR
No Terminal, você escreve e roda código Python de verdade, direto no aparelho. Teste ideias, experimente os exemplos prontos e veja o resultado na hora.

🎮 PYTHONQUEST ADVENTURE
Programe o herói para atravessar o mapa: monte a sequência de comandos, colete a moeda, derrote o bug e chegue ao portal. Consegue resolver cada fase com o menor número de linhas e ganhar 3 estrelas?

🏆 XP, NÍVEIS E CONQUISTAS
Ganhe XP a cada missão, suba de nível, mantenha sua sequência de dias estudando e desbloqueie conquistas e medalhas.

📚 BIBLIOTECA E GLOSSÁRIO
Esqueceu o que é uma variável, um laço for ou uma função? Consulte o glossário com explicações simples e o resumo de cada módulo do curso.

☁️ SEU PROGRESSO SALVO
Use sem cadastro ou crie uma conta gratuita para salvar o progresso na nuvem e continuar em outro celular.

✅ Gratuito e sem anúncios
✅ Ideal para iniciantes, estudantes e quem quer começar na programação
✅ Feito em português

Comece hoje a sua jornada com o PythonQuest!

Python é uma marca registrada da Python Software Foundation. O PythonQuest é um projeto independente, sem vínculo com a Python Software Foundation.
```
